# CodeIbis Tech — Company Website

Adapted from the user-provided `jehanzebali44.github.io` portfolio template. Retains the original layout system, dark gradient aesthetic, reveal animations, cards and mobile navigation, rewritten for CodeIbis Tech.

## Publish
Upload **the files inside this folder**, not the enclosing folder or ZIP, to the root of `codeibisofficial/codeibisofficial.github.io` on GitHub. Keep `index.html`, `style.css`, `company.css`, `script.js`, and `logo.jpg` in the same directory. GitHub Pages: main / root.

## Edit later
- `index.html`: text, services, project cards, links and email.
- `company.css`: new company-specific styles; `style.css` is the original portfolio stylesheet.
- `script.js`: menu, animation and email contact form.
- `logo.jpg`: company logo.

The contact form opens the visitor's email client; it does not send directly or store messages. Portfolio is intentionally a Coming Soon placeholder. No team member profiles or unverified client claims are included.
